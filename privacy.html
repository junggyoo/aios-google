Privacy policy

Last updated: 2026-10-31

  • Who uses it: only the owner (junggyoo.1@gmail.com). It is not offered to anyone else.
  • What it accesses: read-only Google scopes gmail.readonly and calendar.events.readonly. From Gmail it reads only message metadata (subject, sender, date) and Google's short snippet; it never downloads full message bodies or attachments. It never sends, changes or deletes mail or calendar events.
  • Where data goes: data is processed on the owner's own computer. Phone numbers, email addresses and long digit strings are masked before use. Nothing is sold, shared, or sent to third parties for advertising.
  • Storage: the access token is kept in the macOS Keychain on the owner's computer. Mail and calendar contents are not stored.
  • Revoking: access can be removed at any time at myaccount.google.com/permissions.
  • Google API Services User Data Policy: use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
